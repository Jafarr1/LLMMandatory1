# Task Management API

Build a REST API for managing tasks.

## Task

A task contains:

- id
- title
- description
- completed

## Required functionality

The API must support:

- Creating a task
- Getting all tasks
- Getting a task by ID
- Updating a task
- Deleting a task

## Additional requirements

The project must include:

- Automated tests
- Developer documentation
- API documentation
- Deployment configuration
